# ExchangeMart - Your Asset In Motion
A platform that automatically generates deals based on the availability of recycled goods and current projects listed on the exchange board.

“Communities” is a new concept put forth in Version 2.0 and is a way to identify vertical market segments (community) within EXB ecosystem e.g. “Oil & Gas Community”, “Pharmaceuticals Community”. “Communities” allow ExchangeBase to provide more value based services to our end users and help secure better ROI on asset. “Communities” concept is reflected in the Bids and Customer/Buyer workflow.
